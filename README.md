## 关于

- 用代码解决真实问题：C 盘瘦身、投资记账、笔记关联，出发点都是自己的日常
- 关注 AI Agent 与工程流程的结合：让多个 Agent 在同一套项目、需求与提交体系里协作
- 从桌面到手机，把常用工具做成随手可用的形态

## 项目

| 项目 | 说明 | 技术 |
| --- | --- | --- |
| [project-manager](https://github.com/BugStack27/project-manager) | 给自己用的桌面项目管理台：一个窗口看完需求、命令和提交，支持多 Agent 调用与多项目协同 | Electron · React · Vite |
| [project-manager-mobile](https://github.com/BugStack27/project-manager-mobile) | 项目管理台手机端：扫码接入，随时通过、打回、回答待审核与待回答的事项 | Kotlin · Jetpack Compose |
| [obsidian-tag-relation](https://github.com/BugStack27/obsidian-tag-relation) | Obsidian 插件：右侧栏列出与当前笔记共享标签的笔记，按共享标签分组 | TypeScript · Obsidian |
| [obsidian-investment](https://github.com/BugStack27/obsidian-investment) | Obsidian 插件：基金与 A 股交易直接记在笔记里，自动计算持仓与收益，附带净值、K 线与买卖提示 | TypeScript · Obsidian |
| [move-on-link](https://github.com/BugStack27/move-on-link) | 把 C 盘大文件夹搬到别的盘，原位置留链接，程序照常用原路径，C 盘瘦身不折腾 | Tauri 2 · Rust |
